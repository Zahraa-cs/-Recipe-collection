Recipe Collection 🍳

A simple Python OOP project for creating and displaying recipes.

✨ Features

* Create a recipe.
* Add ingredients.
* Enter cooking time.
* Add cooking instructions.
* Display the recipe details.

🛠️ Technologies

* Python
* Object-Oriented Programming (OOP)
* Classes and objects
* Methods
* User input

🚀 How to Use

1. Run the Python program.
2. Enter the recipe name.
3. Enter the ingredients.
4. Enter the cooking time.
5. Enter the cooking instructions.
6. The program displays the created recipe.
